# 🛒 Amazon Sales EDA Project

## Overview
Exploratory Data Analysis on Amazon Sales dataset
using Python, Pandas, NumPy and Matplotlib.

## Libraries Used
- Pandas
- NumPy
- Matplotlib

## Key Analysis
- Data Cleaning
- Price & Discount Analysis
- Category wise Analysis
- Rating Distribution
- Correlation Analysis

## Key Insights
1. Electronics is the most listed category
2. Average product rating is 4.1
3. Discount has very low impact on ratings
4. Computers have the highest average price
